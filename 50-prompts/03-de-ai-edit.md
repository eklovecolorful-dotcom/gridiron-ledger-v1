# 提示詞 3：去 AI 味編修

> 什麼時候用：`ledger check` 通過之後、`ledger approve` 之前，再多一層人眼之外的檢查。
> 腳本查得到禁用詞與句型，查不到翻譯腔，這一步補那一塊。

```
這是我的定稿：
[貼上稿件內文，保留行號]

請只做三件事：
1. 標出翻譯腔（像從英文直譯的句子、不像台灣人會說的詞）。
2. 標出重複句式（連續幾句或幾段用同一種開頭或結構）。
3. 標出沒有來源的數字。

規則：
- 用清單回報行號與原句，各附一句為什麼。
- 不要重寫整篇，不要改我的立場，不要新增內容。
- [[fact:…]] 與 {own:…} 是系統標記，原樣保留。
```

改完之後再跑一次 `ledger check`。內文有改動，核准要重來。
