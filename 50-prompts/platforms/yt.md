# 改寫模板：YouTube Shorts

- 角色：長期搜尋流量
- 長度：口白 60 秒以內
- 寫法：一個動作、一個問題、停格讓觀眾先猜；畫面用自繪戰術圖與原創旁白，不放比賽畫面；說明欄放追蹤連結

> 只在稿件 `approved: true` 之後使用。先執行 `ledger publish <稿件> --platform yt`，把產生的待貼稿貼進下面。

```
這是一篇已經核准的文章，以及程式剪出來的 YouTube Shorts 版本。
請把它改寫成適合 YouTube Shorts 的版本。

要求：
- 長度：口白 60 秒以內。
- 一個動作、一個問題、停格讓觀眾先猜；畫面用自繪戰術圖與原創旁白，不放比賽畫面；說明欄放追蹤連結。
- 只能用原文已有的事實與數字，一個都不能新增或改動。
- 保留我的立場與語氣，用台灣的說法。
- 不要用這些詞：值得注意的是、總而言之、深入探討、全面解析、賦能、無縫、引領、綜上所述、讓我們一起。
- 追蹤連結原樣保留，放在最後。

原文：
[貼上文章全文]

程式剪出來的版本：
[貼上 30-published/<content_id>/yt.md 的內容]
```

改完自己唸一遍，再手動貼到 YouTube Shorts。貼出後執行 `ledger posted <content_id> --platform yt --url <實際網址>`。
