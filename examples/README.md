# examples/

這裡的檔案都是**虛構的示範資料**，只用來試跑指令，不代表任何真實成績。

- `events.sample.csv`：`ledger import-events` 的格式範例（date,src,c,event,amount）。
- `members.sample.csv`：`ledger member import --csv` 的格式範例（example.com 假信箱）。

Synthetic demo data only. The report shows a warning banner while these events are in the database.
